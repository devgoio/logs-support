Logss Support

Open a log

Choose Open Files, drag a text file into the window, or press ⌘O. Use Try Sample to explore without opening personal files. Raw Log shows the original text. Log Stream supports search, severity filters, and timestamp ranges.

Change the display language

Logss supports English and Simplified Chinese. In macOS System Settings, open General → Language & Region → Applications, choose Logs (the installed app) and your preferred language, then relaunch the app.

Configure optional AI analysis

Open AI Settings, choose a provider, and enter an API key and model ID available to your account. Select a log line, review the excerpt, then choose Analyze Excerpt. Local reading and search work without a key.

Contact DevGo

Email lm@usev.cn for help. Include your macOS version, Logss version, and the steps that led to the issue. If an example is needed, send a short redacted excerpt. Keep credentials and private logs out of support messages.

Logss 技术支持（简体中文）

打开日志

点“打开文件”、把文本文件拖入窗口，或按 ⌘O。点“体验示例”可直接试用。原始日志保留原文，日志流支持按关键词、级别和输出时间筛选。

切换显示语言

在 macOS 的“系统设置 → 通用 → 语言与地区 → 应用程序”中选择已安装的 Logs，设置简体中文或英文，重新打开应用即可。

配置 AI 解读

在 AI 接口设置中选择服务商、填写自己的 API Key 和账户可用的模型 ID。选择日志行，检查预览，再点“分析此片段”。本地阅读和搜索可直接使用。

联系 DevGo

请发邮件至 lm@usev.cn，附上 macOS 和 Logss 的版本及复现步骤。如需示例，可附一小段已脱敏的内容，请保留密码、密钥和私人日志在本地。
